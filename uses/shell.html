What's inside

I use Zsh with:

  • Powerlevel10k as prompt (loaded from p10k.zsh)
  • zsh-autosuggestions for inline history suggestions
  • zsh-history-substring-search for smarter arrow-key history
  • zsh-syntax-highlighting for real-time color feedback
  • fzf and zoxide for fuzzy finding and smart cd
  • eza as a modern ls replacement

I also have two custom git functions: push (add + commit + push in one command) and get_commit / apply_commit for syncing commit dates.
